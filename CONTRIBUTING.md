# Contributing

For a rule correction, name the conference, year, track and response stage. Link the official source, identify the affected row and explain what an author would do differently. If a submission form is private, describe only the public rule you can substantiate. A missing public limit can be marked as an invitation-specific field.

For a workflow change, give a small synthetic input, the decision an author needs to make, and the observable outcome you expect. Keep the stage usable on its own. An example for follow-up handling can start with an earlier reply and a new question. [Stage guide](skills/rebuttal/SKILL.md) · [Evaluation exercises](evals/README.md)

Use original synthetic examples for submissions, reviews, results and correspondence. Keep unpublished papers, restricted review content, identifiable case details and personal contact information in the author's own workspace. Use public official URLs for references. An issue or pull request is a public record.

Credit external project ideas with a fixed revision and path. If proposing licensed text or code, identify its source and license and include any required notices. For sources without an explicit license, contribute an independently written description of the design idea. [Source register](SOURCES.md)

# 8. Apply and verify manuscript promises

Start with the author's designated manuscript version, the actual reply or labeled draft, the permitted revision window and the requested editing scope. This stage can run alongside drafting or discussion when the venue permits revision. For planning only, return searchable anchors and proposed local edits.

- Map each commitment to an issue ID, the affected claim, a precise manuscript location, the proposed change and an observable completion condition. Preserve the distinction between a promised addition and a clarification already present in the submission.
- Place a new method detail where a reader would need it to follow the argument. Put the decisive result near the claim it supports, using the appendix for additional conditions. If a premise, metric or numerical claim changes, review its dependent appearances, including relevant captions or conclusions.
- When editing is authorized, modify the designated files and inspect the affected text or rendered table for wording, references and numerical consistency. Preserve existing passages that already answer the question. If an analysis remains pending, mark its commitment as open.
- If the current venue window does not permit a revised submission, prepare an edit map for the next eligible version. Describe a platform upload or reviewer inspection only from a corresponding receipt or comment.

Return the revision map with *issue, commitment, anchor, status and verification*. Mark which changes are proposed, locally applied, uploaded or explicitly seen by a reviewer, using the evidence available for each. Provide the actual edited locations when applicable.

# 4. Draft the first response

Use the reviewer's original questions, the evidence available for each one, the requested language and the applicable response form. Identify the audience, separate or shared fields, length unit, and rules for results, links, attachments and revisions. When a field is unknown, identify it in an author note and draft the useful sections using verified permissions.

For an individual reviewer, open with the answer to their central concern. Use their question numbers or short recognizable headings. Answer each material part, and group linked questions only if a reader can find each answer. In independent response fields, make the answer self-contained. A common response field can explain a shared comparison once and map each implication to the relevant reviewer.

Build each answer around the fact that changes the reader's understanding. State the finding or correction, identify the evidence and explain what claim it supports. Give an exact manuscript anchor for an existing statement or an actual edit. Use future tense for a change the authors have committed to making. If results are pending, write the strongest answer supported today. See the [writing guide](../writing.md) for approach-specific examples.

Return clean, paste-ready text for the intended form. Keep internal evidence paths, outstanding author decisions and counts outside that text. Check coverage in original order and measure the exact final text against the specified unit and field. If space is tight, cut repeated summaries, generic thanks and duplicate methods details before cutting the comparator, decisive result or necessary qualification. Record the draft version and promises so later stages can distinguish drafting from posting.

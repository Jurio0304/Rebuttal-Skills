# 1. Read the submission and the reviews

Start with the version the reviewers saw, its supplement, and the original reviews. Use the author's working revision as a separate source. If only a review is available, identify its explicit requests and mark manuscript support as unchecked.

1. Summarize the central claim in one sentence. Name its strongest existing evidence, the assumptions it needs, and where a reader can find both.
2. Give each substantive review question a stable ID such as R2-Q1. Preserve the reviewer's numbering when available. Record what the reviewer actually asks, what they already accept, and which claim the question affects. Label an inferred concern as an interpretation. Treat a conditional statement about a rating as the reviewer's stated condition.
3. Locate the evidence a reader of the submission could already see. A table can answer a performance question while leaving the proposed explanation open. For a theoretical objection, locate the exact statement, assumptions and disputed proof step.
4. Rank the issues that could change the validity, contribution or usefulness of the work. Explain each priority with the consequence of leaving the issue open. Include important concerns from favorable reviews. Record score scales and confidence only when supplied and relevant.

Return the contribution summary, the priority order, and a compact issue map in original review order. Useful columns are *ID, explicit question, claim at stake, existing evidence and location, remaining gap*. Join related questions by ID while keeping each reviewer's intended comparison. For an analysis-only request, finish with this map.

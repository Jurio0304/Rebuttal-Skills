# 2. Plan the evidence and the response

Use the issue map, available artifacts, venue rules, time and resources. Express the question each proposed action will answer before allocating work.

- For a competing explanation, name the two plausible explanations, the observation that would distinguish them and the factors a comparison must hold fixed. For a proof concern, test the disputed step against its assumptions or derive a counterexample. For a clarity concern, a worked example or an existing appendix passage may be sufficient.
- If you illustrate an assumption with one example, separately check whether the claimed reduction or guarantee follows for the full stated class. Mark that step as pending until the general argument has been supplied.
- Compare the available actions. A precise citation, recomputation from saved outputs, additional baseline, targeted experiment, correction or narrower claim can each close a different gap. Prefer the feasible action whose outcome would change what the authors can honestly say.
- Specify the population, comparison, metric, resources and selection rule needed for an interpretable result. Identify when a proposed analysis or result may be used under the current venue rules. Work shared across reviewers needs one owner and a separate planned answer for each question.
- Before obtaining results, record how a positive outcome, a mixed outcome or an unfinished analysis would affect the response. Set a stopping time early enough to interpret results and edit the draft. Do not commit collaborators or promise experiments unless the author has confirmed that commitment.

Return a prioritized work list with *issue IDs, action, comparison or deliverable, owner if known, cost or time estimate, stopping condition, fallback* and a short outline in each reviewer's original order. Name the first actionable task. A planning request ends with this handoff. Run experiments only within an execution request and the resources the author has authorized.

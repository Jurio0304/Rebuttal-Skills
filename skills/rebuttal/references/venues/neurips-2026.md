# NeurIPS 2026 · Main track

Checked 2026-11-25. Other tracks publish their own instructions.

| Item | Rule for authors |
| --- | --- |
| First round | Authors can see reviews and preliminary meta-reviews. Respond under each review, up to 10,000 characters per review. The form supports plain text and OpenReview Markdown. Check the readers before posting. |
| Evidence and files | New results can appear in the response text. The original submission remains the basis for recommendations. The discussion period accepts neither a revised manuscript nor supplemental uploads. |
| Links | Responses must preserve anonymity and omit links. When a reviewer asks for code, the author may send an anonymized link to the AC through an Official Comment. |
| Discussion | ACs and reviewers gain access to the initial responses when the first phase ends. Authors can then answer follow-ups. Only reviewers and ACs participate in the final discussion phase. |
| Public record | Reviews, meta-reviews and author discussion become public for accepted papers. Rejected papers have an opt-in process. |

Keep the protocol and central result inside the permitted reply. Track promised paper edits for the camera-ready stage if accepted. [Official Main Track Handbook, “Author Responses” and “Publication of Accepted Submissions”](https://neurips.cc/Conferences/2026/MainTrackHandbook)

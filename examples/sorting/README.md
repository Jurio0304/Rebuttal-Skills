# RunFold • a complete fictional rebuttal

Try each step before opening the next file. All names, measurements and messages describe an invented sorting service.

1. Give the assistant the [paper and three reviews](01-intake.md). Ask for the reviewer-specific issues and a plan for one new run. Check that R1 and R2 can share a comparison and R3 needs a different kind of evidence.
2. Reveal the [author's evidence](02-evidence.md). Ask which claim survives, who needs the cold condition, and how strongly correctness can be stated.
3. Draft three replies. Compare against the [initial author responses](03-drafts.md).
4. Invoke independent review of the three drafts. Pass each reviewer only the relevant information from the intake and that reviewer's draft. Let the original R1 agent assess a clarified aggregation method. A [recorded exercise](04-panel.md) shows what the agents actually returned and what the author changed.
5. Introduce the [discussion events](05-discussion-input.md). Ask for one response to the new question, the AC summary and a revision to the submitted claim. Compare with the [worked answer](06-global-and-revision.md).

The exercise uses a made-up venue. For live work, supply the instructions for your actual track and year.
